Política de Privacidade
Aplicativo Clipei

Última atualização: 09 de Dezembro de 2025

Esta Política de Privacidade descreve como o aplicativo Clipei (doravante referido como “Aplicativo”, “Nós” ou “Nosso”), desenvolvido por Vitor Gabriel Batista de Souza (“Desenvolvedor”), coleta, usa, armazena e compartilha informações quando você utiliza nosso aplicativo móvel.

Ao utilizar o Clipei, você concorda com as práticas descritas nesta política.

1. Informações que Coletamos

1.1. Dados Pessoais Fornecidos Pelo Usuário (Dados de Conta)

Caso o aplicativo ofereça ou exija autenticação, poderemos coletar:

  • Identificadores: Nome completo e endereço de e-mail.
  • Credenciais: Dados de acesso ou identificadores únicos utilizados para proteger sua conta.

1.2. Dados Coletados Automaticamente

  • Informações de Uso: Interações, páginas acessadas, tempo de uso e data/hora.
  • Informações Técnicas: IP, tipo de dispositivo, sistema operacional e identificadores exclusivos.
  • Logs de Servidor: Registro de vídeos acessados via API.

2. Uso da Informação

Utilizamos os dados coletados para:

  • Fornecer e manter o serviço de replays esportivos.
  • Garantir segurança, autenticação e controle de acesso.
  • Processar downloads de vídeos para o seu dispositivo.
  • Analisar desempenho, identificar problemas e otimizar o App.

3. Permissões Essenciais do Dispositivo

  • Armazenamento / Galeria: Exclusivamente para salvar vídeos baixados. Nenhuma outra mídia é acessada.
  • Acesso à Internet: Necessário para streaming, autenticação e comunicação com a API.

4. Compartilhamento de Informações

Não vendemos ou comercializamos seus dados pessoais. Podemos compartilhar apenas com:

  • Provedores de Serviço: Hospedagem, processamento e relatórios de erro (ex.: Firebase).
  • Autoridades Legais: Quando exigido por lei ou ordem judicial.

5. Segurança dos Dados

Utilizamos medidas razoáveis de segurança, incluindo HTTPS (SSL/TLS). Contudo, nenhum sistema é 100% seguro.

6. Retenção de Dados

Dados pessoais são mantidos apenas pelo tempo necessário para as finalidades descritas. Logs técnicos podem ser retidos por períodos menores, salvo exigência legal.

7. Seus Direitos (LGPD)

Você pode solicitar:

  • Acesso aos dados armazenados.
  • Correção de dados incorretos.
  • Exclusão de dados pessoais.
  • Restrição ou oposição ao processamento de dados.

Para exercer seus direitos, utilize o e-mail indicado na seção final.

8. Alterações a Esta Política

Atualizações poderão ocorrer periodicamente. Alterações relevantes serão comunicadas dentro do aplicativo.
